# Frontend Audit Checklist

Run this checklist before finishing frontend polish.

## Visual Quality

- Page title, subtitle, primary action, and active module are easy to identify.
- Spacing has rhythm: not every gap is identical, not every block is a card.
- Borders are consistent and subtle.
- Shadow use is sparse and purposeful.
- Accent color is meaningful, not decorative.

## Typography

- Body text contrast is comfortable.
- Labels are readable and not overly faint.
- Numeric values use tabular alignment where possible.
- Long strings wrap or truncate intentionally.
- Buttons can handle Portuguese text without overflow.

## Layout

- No nested cards.
- Tables scroll horizontally when needed.
- Fixed-format controls do not resize on hover.
- Desktop and mobile grids do not overlap.
- Sidebar/topbar states stay readable in light and dark themes.

## States

- Buttons, inputs, selects, nav items, tabs, and table actions have hover/focus states.
- Disabled/loading/error states are visible where relevant.
- Empty states give a next action.
- Calculation/result blocks clearly show inputs, outputs, and source.

## Anti-Patterns

- No gradient text.
- No decorative orbs/blobs.
- No thick colored side stripes.
- No endless same-card grid.
- No low-contrast gray text on tinted backgrounds.
- No generic purple-blue SaaS palette.
