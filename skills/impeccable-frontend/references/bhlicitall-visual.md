# BHLicitAll / TLPlanly Visual Reference

Use this reference when the user asks for the project to look like BHLicitAll, more premium, more professional, or less rough.

## Brand Read

BHLicitAll's public site uses a consulting/premium-service posture: light surfaces, confident gold, direct business proof, Inter/Poppins typography, restrained contrast, and clean sectioning. TLPlanly should inherit the credibility, not the marketing-page composition.

## Tokens

Use these as project-level direction, not as mandatory exact values:

- Brand gold: `#c9a961`
- Gold hover: `#d8bb78`
- Deep ink: `#1d1a14`
- Body text: `#342f24`
- Muted text: `#6f6758`
- Page background: `#f6f3ec`
- Raised surface: `#fffdf8`
- Sidebar/topbar surface: `#fbf8f1`
- Soft rule: `#e4dccb`
- Strong rule: `#cdbf9f`
- Success: `#2f7d52`
- Warning: `#b17913`
- Error: `#b23b35`

## Typography

- Use `Inter` for product UI: tables, labels, forms, body text, navigation.
- Use `Poppins` for logo, page titles, and occasional display emphasis.
- Keep product headings compact. A dashboard title should feel like a command surface, not a landing hero.
- Avoid italic headings for app UI unless the brand lockup specifically needs it.
- Use `font-variant-numeric: tabular-nums` for prices, quantities, percentages, and totals.

## Lines and Borders

- Prefer 1px borders with warm-neutral color.
- Use slightly stronger borders for active modules, selected tabs, and focused inputs.
- Avoid heavy dark outlines and thick colored side rules.
- Tables should use quiet row dividers and a slightly tinted header band.
- Cards/panels should have soft shadows only when they need elevation.

## Color Use

- Gold is for primary actions, selected navigation, important metrics, and trust/proof accents.
- Do not make every heading gold.
- Use dark text on gold buttons.
- Avoid pure black. Use warm ink and charcoal.
- Avoid saturated blue/purple gradients for this brand.

## Product Application

For TLPlanly:

- Topbar and sidebar should feel like a professional SaaS workspace.
- Main content should breathe, but keep density for repeated estimating work.
- Forms should be aligned, with predictable labels and compact controls.
- Calculation previews should look like technical memos: structured, bordered, and readable.
- Tables should emphasize numbers and actions without visual noise.

## What To Avoid

- Marketing hero layouts inside the app shell.
- Dark-heavy panels that obscure data.
- Gold-on-gold or low-contrast muted text.
- Decorative blobs, bokeh, or generic gradients.
- Oversized rounded cards that make the tool feel toy-like.
